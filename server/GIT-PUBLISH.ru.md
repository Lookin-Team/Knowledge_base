# Публикация кода в корпоративный GitHub

Репозиторий: https://github.com/Lookin-Team/Knowledge_base .
Remote `company`, ветка назначения `main`. Remote `origin` сохранён для
официального BookStack. Рабочая локальная ветка — `local/bookstack-dev`.

16.11.2026 проверены чтение репозитория и право обычной fast-forward отправки
новым отдельным SSH-ключом. Локальная настройка `core.sshCommand` использует
новый ключ и закреплённые ключи хоста GitHub, без SSH agent и отключения
проверки хоста. Закрытый ключ хранится вне репозитория в `.server-access/`.
На другом устройстве потребуется собственная авторизация.

Замена ключа разрешает отправку, но не включает автоматическую публикацию.
В проекте не настроены наблюдатель файлов, Git-hook или GitHub Actions для
автоматического коммита/отправки либо обновления VPS. Публикация кода в GitHub
и развёртывание сайта на VPS — отдельные действия.

Перед отправкой: проверить изменения, исключить секреты/данные/журналы,
выполнить применимые проверки, создать коммит и отправить обычным push.
Не использовать `git add .` для папки local-dev с рабочими отчётами и файлами.
Изменения на GitHub сначала получить и сверить с локальной историей;
не использовать force-push для разрешения расхождений.

При публикации 16.11 синтаксис Python и поиск известных production-секретов
проверены. PHPUnit для обновлённого теста отзыва/истечения ключей повторно
не запускался: Docker Desktop недоступен. Это не успешный прогон PHPUnit.
Предыдущие проверки развёртывания и резервирования описаны отдельно.
Расписание резервного копирования остаётся выключенным по указанию владельца.
