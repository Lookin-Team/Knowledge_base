## Откат

Восстановить защищённые deploy.env.before и app.env.before в их исходные пути,
затем выполнить от root на VPS:

```
docker compose --env-file /opt/lookin-base/deploy.env -f /opt/lookin-base/server/compose.yaml up -d --no-deps --wait app
```

Предложка отключится, таблицы и заявки сохранятся. Не удалять тома и не
восстанавливать старую БД поверх новых записей без отдельной оценки сохранности.
Повторный запуск deploy-proposals.py на уже обновлённом сервере блокируется
проверкой исходного образа. Для следующего выпуска нужна новая версия процедуры.
